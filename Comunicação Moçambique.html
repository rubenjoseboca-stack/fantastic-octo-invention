Como Hospedar este Site Grátis e Partilhar o Link

Siga este guia simples para colocar o seu site Comunicação Moçambique online gratuitamente na internet utilizando serviços como GitHub Pages, Netlify ou Vercel.

1

Netlify Drop (Sem Código)

A forma mais rápida sem precisar de instalar nada.

  1. Guarde este código num ficheiro com o nome index.html no seu computador.
  2. Aceda ao site app.netlify.com/drop.
  3. Arraste a pasta que contém o ficheiro index.html para a página.
  4. Em menos de 1 minuto o Netlify gera um link público grátis para partilhar!
2

GitHub Pages

Ideal para manter o projeto guardado e atualizado.

  1. Crie uma conta gratuita em github.com.
  2. Crie um novo Repositório público (ex: comunicacao-mozambique).
  3. Carregue o ficheiro index.html.
  4. Vá às Settings > Pages e ative o branch main. O seu link será gerado automaticamente.
3

Vercel

Excelente velocidade e domínio gratuito personalizado.

  1. Aceda a vercel.com e crie conta.
  2. Importe o seu repositório do GitHub ou utilize a ferramenta de upload direto.
  3. Clique em Deploy. O site ficará no ar com certificado SSL (HTTPS) gratuito.

Como Partilhar o Seu Link em Moçambique

Assim que tiver o seu link (ex: https://comunicacao-mozambique.netlify.app), pode partilhá-lo via WhatsApp, redes sociais, SMS ou adicionar aos grupos comunitários para dar acesso instantâneo aos contactos e publicações locais.
